# Review link explanations critically

A Bible study site links New Testament verses to Old Testament verses and
shows readers a short explanation of each link. The site takes no doctrinal
position: its own words must be acceptable to readers of every tradition. You
are the critical reviewer.

Each item: `id`, `kind`, `node`, `nt`, `ot`, `explanation` (the text to
review), `beats` (story echoes only), `verses` (the Berean Standard Bible text
of both verses and of every verse the explanation cites), and `context` (two
verses each side of both).

What the kinds claim:
- `words_taken_up` -- the NT verse quotes or closely reproduces this OT verse's
  wording.
- `shared_image` -- both verses use the same image or expression (`node` names
  it); NO claim that one points to the other.
- `story_echo` -- the two passages tell stories whose beats match; `beats` pair
  the exact words.

**Review each explanation on three tests.**

1. **Faithful to the text.** Every quotation is the Berean's exact words from
   the verse it is attributed to (check against `verses`); every statement is
   what the verses say. Flag a wrong quote, a wrong reference, a count or an
   "only"/"no other" claim the verses given cannot support, and any motive,
   meaning, significance or evaluation the text does not state. For
   `shared_image`, flag any wording that says one verse points to, draws on or
   refers to the other.

2. **Kind.** Flag a `words_taken_up` whose wording is not close enough to
   claim the NT verse takes up these words, and a `shared_image` where the NT
   verse plainly quotes this OT verse (an introducing formula, word for word).

3. **Acceptable to all.** Read it as each of these would, looking for any word
   that takes a side: evangelical Baptist, Calvinist (Reformed), Arminian,
   Lutheran, Methodist (Wesleyan), Charismatic/Pentecostal, Eastern Orthodox,
   and a secular academic biblical scholar. Watch especially:
   - the site's own voice saying an OT text "fulfils", "foreshadows",
     "predicts" or "is about" something, or that an author "meant" it (fine
     when quoted as the text's own words: "Matthew introduces it with 'to
     fulfill what was spoken'");
   - Daniel, Revelation, Ezekiel, Zechariah and other prophecy: say what each
     text says and nothing more -- never that two visions describe the same
     thing, never what or when a vision refers to, nothing that favours one
     way of reading prophecy (a timeline, a future-or-past reading, Israel and
     the church, a millennium). Plain shared wording must still be stated
     plainly: hiding an obvious connection is a failure too;
   - Israel, the covenants, the law, sacraments, the nature of Christ.

Verdict:
- `"ok"` -- passes all three.
- `"revise"` -- give the objection(s) (which test or tradition, which words,
  why) and a `revision`: the explanation fixed, 2-4 sentences, quoting only
  the Berean exactly with the verse, staying as informative as the original.
  If the kind is wrong, say so in `kind_should_be` (`words_taken_up`,
  `shared_image`, `story_echo` or `drop`) and write the revision for that kind.

## Output

For the file `C_NN.json` you are given, write `CR_NN.json` in the same folder:
a JSON list, same order, exactly as many entries as the input:

```json
[{"id": 0, "verdict": "ok|revise",
  "objections": ["<test or tradition: the words, and why>"],
  "kind_should_be": "<only if the kind is wrong, else null>",
  "revision": "<only when revise, else null>"}]
```

Valid JSON only; count the entries. Write no other files.
