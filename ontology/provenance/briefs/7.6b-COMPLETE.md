# What a side-by-side row left out

A Bible website's theme pages have tables setting side by side how
different books use the same words. Each row has cells (a verse and the
words that carry the match), and two lines in the site's voice, **Alike** and
**Different**. A machine searched the whole Berean Standard Bible for other
verses with the wording the row's cells share, and found the candidates in
your packet. Some belong; most are a common phrase that happens to match.

For each candidate, decide:

- `add`: the verse speaks of the **same thing** the row shows, in the row's
  own distinctive words ("book of life" in Psalm 69:28 beside Revelation's;
  "prepare the way" in Luke 3:4 beside Isaiah 40:3). It goes in the row.
- `aside`: the verse uses the row's **own distinctive words** -- the words
  the row is named for -- but of **something else** ("A soothing tongue is a
  tree of life", Proverbs 15:4, beside the tree of life in Genesis and
  Revelation). It goes in the row with an asterisk and the note "Off the
  theme's subject, and shown because it uses the same words." Use this only
  for the row's distinctive words, never for a common phrase.
- `skip`: the match is a common phrase that is not what the row is about
  ("what kind of", "you have taken", "she gave birth", "will pour out" of
  wrath where the row is about the Spirit).

Be strict with `add` and `aside`: a reader who sees the verse in the row must
see at once why it is there.

For `add` and `aside`, give the column it belongs in (one of the row's
table's columns, listed in the packet), and **the words that carry the
match, copied exactly** from the verse given in full.

If you add or set aside anything, give the row's `alike` and/or `different`
rewritten with the smallest change that takes the new verses in, quoting
only the row's verses, in the same plain voice: say what the texts say, never
what anything means, whether one passage looks forward to another, or why
it was written. Otherwise `null`.

## Output

Write a JSON array to the path you are given, one object per row in the
packet:

```json
[{"table": "new_creation", "row": 13,
  "candidates": [{"verse": "Proverbs 15:4", "verdict": "aside", "column": "Psalms & elsewhere",
                  "words": "A soothing tongue is a tree of life"},
                 {"verse": "Judges 5:31", "verdict": "skip"}],
  "alike": null, "different": "..."}]
```

Reply with one line: how many add / aside / skip.
