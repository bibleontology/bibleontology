# The hundred people outside sources treat as central
#
# The graph has dug into some lives far more than others, and the reason is
# extraction order rather than judgment. The corpus is in large part a
# narrative, and a graph that downplays its people to favour concepts has
# traded one lopsidedness for another.
#
# THE QUESTION THIS FILE ASKS is not "is this person in the graph". Almost all
# of them are, with kin and places and events. It is:
#
#     Does this person have their burning bush, and does the graph have it?
#
# The bush is the test case. It is in the Moses story, it is the most
# recognisable image attached to him, and for a long time this graph held it as
# an orphan with no verses and no connections -- present, and saying nothing.
# A reader who came to Moses would not have found it.
#
# So for each name: what is the image, object, saying or figure that a reader
# associates with this person, and is it in the graph, cited, and reachable
# from them? Some will have none, and that is an answer. Some will have
# several. The ones to worry about are the ones where a figure obviously
# exists and the graph has the person without it.
#
# Ordered by the tiers as given, which are a rough proxy for how likely a
# reader is to arrive already knowing something.
#
# Format: tier | name | the figure(s) a reader would expect | status
