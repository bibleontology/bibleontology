# One hundred tangible things a reader expects the graph to hold. Overlaps the
# symbol checklist deliberately: that list asks whether a meaning was recorded
# without being invented, this one asks whether the thing itself exists at all.
# Tier 0, not tier 1.
#
# Format: <n>\t<item>\t<KJV search word>
#
# ---------------------------------------------------------------------------
# HOW TO SCORE IT
#
# Four classes, and only the first is a straight recall count.
#
#   A. A thing in the world, named by the text.  The ark, the ephod, the
#      mercy seat, the stone tablets, Goliath's sword. Expected: an entity.
#      Missing one is a recall failure and nothing else.
#
#   B. A thing that exists only inside a told image.  The house built on sand
#      (Matt 7:26), the sheepfold (John 10:1), the vineyard wall (Isa 5:5),
#      the mustard seed of the parable. There is no such house and no such
#      wall. Minting these as objects files them beside the ark as though they
#      were the same kind of thing, which is the error this list is best at
#      provoking. Expected: whatever the told-image decision settles on, and
#      NOT an object entity.
#
#   C. A category, not a thing.  "Musical instruments", "altars built by
#      patriarchs", "garments of righteousness". These name a class or a
#      figure of speech. Expected: nothing, or the specific members if the
#      text names them.
#
#   D. Not the corpus's word.  Menorah is candlestick; shofar is trumpet;
#      denarius is penny; lyre is harp or psaltery. Searching for the modern
#      term finds nothing and that is not a gap. Expected: the entity under
#      the KJV name, if it exists at all.
#
#   E. A common noun, not an individual.  Sword appears 384 times, sea 352,
#      bread 330, altar 321. There is no entity called "sword" any more than
#      there is one called "man" -- what can be an entity is *a* sword the
#      text singles out: Goliath's, taken by David from behind the ephod
#      (1Sam 21:9). This is the largest class on the list and the easiest to
#      score wrongly in both directions: counting the word as a hit inflates
#      recall, and counting it as a miss demands nodes that should not exist.
#      Expected: entities for the singled-out instances, nothing for the class.
#
# Report recall on class A. Report class B separately and treat any object
# entity there as a defect. Classes C, D and E test the reader of the results
# as much as the graph.
#
# ---------------------------------------------------------------------------
# BASELINE, 18 August 2026, before any work against this list
#
#   entity exists    8, of which 2 are artefacts of naive name matching:
#                    "bow and arrows" matched the bow in the cloud, which is
#                    the rainbow, and "cloud" matched the pillar of cloud
#                    through an aka. The true figure is 6.
#   no entity       92
#
# The largest gaps by frequency are all class E -- sword, sea, bread, altar,
# wilderness -- which is the strongest argument on this page for settling what
# an object entity *is* before extracting against the list. A run that mints
# `sword` has not made progress; it has made a dictionary.
#
# ---------------------------------------------------------------------------
