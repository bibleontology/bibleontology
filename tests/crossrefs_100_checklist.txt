# A hundred phrases the corpus says more than once
#
# The spine list: sentences and formulas that recur across books, testaments
# and centuries, with the places they recur given.
#
# THE QUESTION THIS FILE ASKS is different from the other checklists, and it is
# the one this graph is best shaped to answer:
#
#     Are the recurrences reachable from each other, and does the graph say
#     which of them the corpus itself connects?
#
# That last clause is the whole discipline. Some of these chains are stated:
# Matthew 1:23 quotes Isaiah 7:14 and says so. Hebrews 10:38 quotes Habakkuk
# 2:4 and says so. Others are a resemblance a reader notices -- "let there be
# light" and "God, who said, 'Let light shine out of darkness'" (2 Cor
# 4:6) are plainly related and Paul does not cite Genesis.
#
# **A stated quotation and an unstated echo are different facts and must not
# be recorded the same way.** The graph has `quoted` for the first. For the
# second it has the phrase layer, which finds shared wording without claiming
# intent, and descriptions, which can say "and no verse joins them".
#
# A row is done when each end is cited, the ends reach each other, and the
# manner of the connection -- quotation, allusion, or a reader's observation --
# is visible rather than flattened.
#
# Several rows repeat by design: 5 and 72 are both the shepherd, 26 and 98 both
# the refuge, 29 and 94 both the helper, 20 and 93 both "the just shall live by
# faith". The list is a reader's memory, not a schema, and the duplication is
# a fact about which phrases carry the most weight.
#
# Instrument: `bibleont.phrases` finds shared wording; `bibleont.patterns`
# finds shared construction; `bibleont.citations` finds stated quotations.
#
# Format: n | phrase | references | status
