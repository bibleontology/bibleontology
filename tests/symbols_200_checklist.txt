# Two hundred symbols, with the sense a reader arrives expecting
#
# THE QUESTION THIS FILE ASKS is not "is the word in the corpus" -- almost all
# of them are, and a concordance answers that. It is:
#
#     Does the graph hold this as a figure, cited, and reachable from the
#     passages that use it -- and does it hold the sense without asserting it?
#
# The second half matters more than the first. Every row carries a gloss
# ("rainbow -- covenant mercy") and **those glosses are the reader's, not the
# corpus's**. A few are stated in the text: 1 Peter 3:21 says the ark is a
# figure of baptism, John 3:14 says the brazen serpent is a figure of the Son
# of man, Genesis 9:13 says the bow is a token of a covenant. Most are not.
#
# So the rule this file is scored against is the one the imagery layer already
# follows. Where the corpus states the meaning, it is recorded as a stated
# thing with the verse that states it. Where the meaning is a tradition's
# reading -- however good a reading -- it stays in this column and out of the
# graph. A row is done when the figure exists, is cited, and reaches the
# material that uses it. **It is not done by adding an edge asserting the
# gloss**, and a row that acquired one would be a defect rather than progress.
#
# Some entries are the same word twice with different senses (1 and 92 are both
# the rainbow; 21 and 130 are both a yoke). That is the list being honest about
# how the corpus uses them, and the graph holds one record per word with the
# senses in its description, not one record per sense.
#
# Instruments: `image` records are minted only where the corpus uses a word
# figuratively more than once, and are kept apart from the tangible thing of
# the same name by `drawn_from`. `bibleont.candidates` finds figures that share
# verses with material they do not reach.
#
# Format: n | symbol | the sense a reader expects | status
